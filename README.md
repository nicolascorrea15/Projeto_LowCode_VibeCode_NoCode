# Projeto_LowCode_VibeCode_NoCode
Projeto referente a unidade 3 da disciplina Engenharia de prompt e aplicações em IA
Projeto de um portfólio online para estudantes de tecnologia, projeto em colaboração dos estudantes Nicolas Correa, Felipe Sales e Pedro Paulo
O projeto funciona como um currículo online para facilitar estudantes atualizarem suas informações, trabalhos e contatos 
Foi utilizado a plataforma Lovable, usando o metódo vibe code, ensinado nas aulas da disciplina. 
O foco do projeto foi criar uma plataforma simples de ser usada e direta com as informações apresentadas, onde o estudante pode estar atualizando o site conforme necessário de forma simples.
