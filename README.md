# Projeto: Portfólio Online

Projeto de um portfólio online para estudantes de tecnologia e de outras áreas poderem anexar suas informações, projetos acadêmicos e projetos pessoais, contato para projetos e trabalhos.


## Protótipo
Aplicação: [Link da aplicação](https://nicolascorrea15.github.io/Projeto_LowCode_VibeCode_NoCode/portfolio.html)

O site funciona como um currículo, porém online, para que o usuário possa divulgar seu trabalho ou utilizar como exposição em redes sociais

## Plataforma utilizada - [Lovable](https://lovable.dev/pt-br)

Foi utilizado o Lovable como plataforma de vibe code para nossa apicação pois ele é totalmente traduzido para o português e de simples entendimento, o que facilitou no processo de criação, uma vez que era a primeira vez que faziamos um processo como esse.

Dentre as vantagens dele estão:
1. A tradução em portuguẽs.
2. A facilidade de utilização e personalização, apenas um prompt e a página fica pronta, permitindo que nós a alterassemos e voltassemos caso o resultado saisse fora do esperado.
3. A integração do GitHub, ele tem integração direta com a plataforma, o que deixa fácil o processo de documentação e versionamento da aplicação.

Limitações:
1. É  necessário adquirir um plano pago para que possa fazer a publicação da aplicação na web.
2. Ele realiza muito bem o que foi pedido, porém depende de prompts bem escritos para um resultado realmente satisfatório.
3. Em caso de personalizações muito especifícas a IA do lovable acaba se perdendo e não entregando um resultado satisfatório

## Reflexão crítica

1. Para a limitação do plano pago, decidimos deixar a aplicação focada apenas em uso "local", sem publicá-la no momento
2. Utilizamos de prompts diferentes em outras plataformas para conseguir chegar no prompt ideal, também utilziamos dos conhecimentos do material disponível no blackboard para refinar o prompt antes de enviá-lo para a plataforma.
3. Para personalizações mais específicas, usamos IAS diferentes para alterar diretamente no código a personalização que queríamos.
